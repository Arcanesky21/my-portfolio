# Mikarlo Francis Portfolio

A modern, responsive portfolio website for Mikarlo Francis, a full stack developer specializing in Angular, .NET, Next.js, and scalable web solutions.

## Features
- Animated page transitions and custom stair effects
- Responsive design for all devices
- Professional resume, services, and contact sections
- Skills and experience showcase
- Social media integration
- Built with Next.js 15, React 19, Tailwind CSS 4, and Framer Motion

## Tech Stack
- **Framework:** Next.js (App Router, Server Components)
- **Styling:** Tailwind CSS, custom CSS
- **Animation:** Framer Motion
- **UI:** Radix UI, React Icons
- **TypeScript**

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) to view the site.

## Project Structure
- `src/app/` — Main app directory (pages, layout, global styles)
- `src/components/` — Reusable UI and layout components
- `public/assets/` — Images and static assets

## Customization
- Update your information in `src/app/(public)/resume/page.tsx` and `src/app/(public)/services/page.tsx`.
- Add or update projects in `src/app/(public)/work/page.tsx` and `public/assets/work/`.

## Deployment
Deploy easily on [Vercel](https://vercel.com/) or any platform supporting Next.js 15.
